# Kasawo Yaffe

**Kasawo Yaffe** ("our Kasawo") is the online home of Kasawo, Mukono District, Uganda: its history and culture, places to visit, a marketplace for local businesses, community advice, and donations.

| Folder | What it is |
|---|---|
| [`site/`](site/) | **The website**: Laravel 13 + Blade, with an admin area at `/admin`. See [site/README.md](site/README.md) to run it. |
| [`mockup/`](mockup/) | The original static design mockup (open `mockup/index.html` in a browser). |
| [`web/`](web/) | An empty Next.js starter, not used by the site. |

Photos are freely licensed stand-ins from Wikimedia Commons; credits are in [`site/public/images/CREDITS.md`](site/public/images/CREDITS.md).
